# Assets

This folder contains production-ready visual assets for the GoHighLevel implementation.

## Included
- `icons.svg` — reusable outline icon sprite for all landing-page UI icons.
- `ai-opportunity-report.svg` — scalable hero/report-preview visual with clearly illustrative data.

## Icon usage
Use:
```html
<svg class="dino-icon" aria-hidden="true"><use href="/assets/icons.svg#calendar"></use></svg>
```

Available IDs:
`check`, `pin`, `shield`, `users`, `chart`, `phone`, `calendar`, `message`, `document`, `database`, `bolt`, `robot`, `workflow`, `eye`, `target`, `search`, `clipboard`, `arrow-right`, `clock`, `lock`, `star`.

## Brand logo
The official DinoCodeLA dark and white/purple logos were supplied in the project conversation, but are not recreated here. Do not substitute or redraw them. Upload the original PNG/SVG logo files to GoHighLevel Media Library and use those hosted URLs.

## Founder photo
Use Walter Cueva's real approved photo only. Never generate or substitute a face. If the approved source photo is not present in the repo, obtain it before publishing.

## Fonts
No font binaries are required. The CSS currently uses Inter with system fallbacks. If the live DinoCodeLA site uses a hosted webfont, load it from the same approved source rather than committing font binaries.
