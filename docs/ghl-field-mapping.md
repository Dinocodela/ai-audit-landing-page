# GoHighLevel Field Mapping

Use the existing GoHighLevel contact/custom fields whenever equivalent fields already exist. Do not create duplicates without checking first.

| Landing Page Field | Preferred GHL Mapping |
|---|---|
| Business Name | Company Name / existing business-name field |
| Your Name | Contact Name |
| Email | Contact Email |
| Phone | Contact Phone |
| Website | Website / existing custom field |
| Industry | Existing Industry field or custom field |
| ZIP Code | Postal Code / custom field |
| Team Size | Custom field |
| Biggest Operational Challenge | Custom long-text field |

## Suggested Qualification Values
Team Size:
- 1–5
- 6–10
- 11–25
- 26–50
- 51+

## Funnel State
Recommended progression:
Landing page → Start application → Lead captured → Calendar → Appointment booked → Qualified lead → Discovery call → On-site audit → Report delivered → Optional implementation conversation

## Critical Rule
Do not break or replace existing automations simply to match these names. Inspect the existing GHL setup first and map the new landing-page experience into the current CRM/workflow structure.
