# Design Specification

## Direction
Premium business diagnostic, not a generic AI agency landing page.

The page should feel:
- Credible
- Modern
- Business-first
- Local to Los Angeles
- Human
- High-value
- Easy to scan on mobile

Avoid:
- Generic robot artwork
- AI brains
- Circuit-board backgrounds
- Overdone neon tech effects
- Stock businessmen
- Excessive gradients or decorative elements competing with CTAs

## Layout
Use generous whitespace and strong section separation. Desktop content should generally sit inside a centered max-width container around 1180–1240px. Mobile should use roughly 20px side padding.

## Typography
Use the same/similar typography family as the main DinoCodeLA website when available in GoHighLevel. Headings should be bold, compact, and readable. Body copy should be comfortable at 16–18px desktop and at least 16px mobile.

## CTA
Primary CTA must have strong contrast and a large touch target. Keep CTA wording consistent around qualification rather than immediate booking.

Preferred primary CTA:
See If My Business Qualifies →

Secondary CTA where useful:
Get My Free AI Audit →

## Hero
Desktop: two columns, copy left and report mockup right.
Mobile: copy first, CTA, trust notes, then report mockup.

The report mockup should visually communicate tangible deliverables within seconds.

## Trust Strip
Compact and easy to scan. Use only claims that can be substantiated. Do not fabricate social proof.

## Cards
Use cards selectively for pain points, report findings, process steps, industries, and FAQ. Keep corner radii and shadows consistent.

## Founder
Use Walter's real approved image only. Never generate or substitute his face.

Desktop: photo left, copy right.
Mobile: photo first, then copy.

## Report Preview
This should be one of the strongest visual sections on the page. Make the report feel like a tangible consulting deliverable rather than a generic checklist.

Any example figures must carry an `Illustrative example` label.

## Forms
Use native GoHighLevel forms for CRM/workflow compatibility. Visually style the wrapper to match the custom page.

Preferred flow:
1. Business
2. Operations
3. Contact
4. Calendar

## Mobile
The Meta ad audience will be mobile-heavy. Treat mobile as a primary layout, not a desktop adaptation.

Requirements:
- Main value proposition visible immediately
- CTA visible in first screen or directly below core copy
- 44px+ touch targets
- No horizontal scroll
- No giant paragraphs
- Cards stack naturally
- Sticky CTA should not cover form fields or calendar controls

## Footer
Include DinoCodeLA, Los Angeles, California, Veteran Founded, Privacy Policy, and Terms of Service. Use the official logo asset when available.
